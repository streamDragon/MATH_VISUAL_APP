# פרומפט לסוכן במחשב עם Kokoro

חגי ביקש להוסיף קולות לאפליקציה מתוך ההתקנה המקומית שלו. אין גישה למחשב הזה מסביבת הפיתוח הנוכחית. צלילי הצלחה מקומיים כבר עובדים; קובצי קריינות טרם נוצרו.

## העתק לסוכן

אתה עובד במחשב של חגי ויש לך הרשאה להשלים קובצי קריינות מוכנים מראש לפרויקט `streamDragon/MATH_VISUAL_APP`. אל תחבר AI או TTS בזמן שימוש תלמידים. התלמידים מקבלים רק קובצי MP3/WAV.

1. משוך את הגרסה האחרונה ושמור שינויים קיימים. מצא את התקנת Kokoro הפעילה, את ה־Python/סביבת העבודה שלה ואת הממשק הזמין; אל תתקין גרסה נוספת לפני שבדקת את הקיימת.
2. בדוק אילו שפות וקולות נתמכים **בהתקנה הזאת**. אין להניח שקיים קול עברי ב־Kokoro. אם אין עברית איכותית, הקלט קול אנושי עברי מקומי, או השתמש בכלי המקומי שחגי כבר בחר לעברית. אל תיצור עברית עם קול אנגלי ותכריז שהצליח.
3. הפק קליפים קצרים, רגועים ומכבדים בני נוער. ללא מוזיקת רקע, ללא שמות תלמידים וללא ניסוחים שמביישים טעות. השאר מעט שקט בתחילה ובסוף, ומנע clipping. האזן בעצמך לכל קליפ.
4. שמור תחת `public/audio/learning/he/` ו־`public/audio/learning/en/`. העדף MP3 קטן; WAV נתמך גם כן. עדכן `public/learning-voices.json` כך ש־`clips` ממפה כל מזהה למחרוזת הנתיב היחסי, לדוגמה `"he_explore":"audio/learning/he/explore.mp3"`. הנתיבים חייבים להתאים לפורמט הקיים; אין URL חיצוני.
5. מזהים וטקסט:

| מזהה | נוסח |
|---|---|
| he_explore | שנו פרט אחד בציור. מה השתנה, ומה נשאר אותו דבר? |
| he_hint | חברו בין הנתונים, הציור והנוסחה. נסו לתאר את הקשר במילים שלכם. |
| he_transfer | עכשיו הנתונים השתנו. בנו את התמונה בראש לפני שאתם מחשבים. |
| he_success | הצלחתם להשתמש ברעיון גם בשאלה חדשה. עוד צעד של הבנה. |
| en_explore | Change one part of the picture. What changed, and what stayed the same? |
| en_hint | Connect the values, the picture and the formula. Describe the connection in your own words. |
| en_transfer | The values have changed. Build a picture in your mind before calculating. |
| en_success | You used the idea in a new question. One more step in understanding. |

6. הקוד כבר קורא `playVoice` אחרי פעולת משתמש. ודא שהשתקה עוצרת גם קריינות ושאין autoplay. הוסף את הקליפים הקטנים ל־`APP_SHELL` ב־`public/service-worker.js`, סנכרן את העותק בשורש ועדכן את גרסת המטמון כדי לאפשר שימוש חוזר offline. אין להכניס קובצי קול שלא קיימים לרשימת המטמון.
7. הרץ `npm test`, `npm run build` ובדיקת דפדפן עם ובלי סאונד בעברית ובאנגלית. הקשב בטלפון אמיתי, בדוק השתקה באמצע קליפ ולמידה ללא רשת אחרי טעינה ראשונה.
8. שמור ופַרסם את הקבצים עם פירוט של כלי ההפקה, קול, שפה ורישיון שימוש מסחרי כפי שנבדק בפועל. אם שפה לא הושלמה, השאר את המזהים שלה חסרים ודווח על כך; האפליקציה ממשיכה בלי הקריינות הזאת.

אין חובה להוריד תוכנה נוספת אם ההתקנה הקיימת מסוגלת לבצע את המשימה. לעריכת קול אפשר להשתמש בכלי שכבר נמצא במחשב.
